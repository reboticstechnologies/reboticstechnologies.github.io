GitHub Pages:
1. Upload all files/folders, keeping the assets folder.
2. In repository Settings > Pages, select the branch/folder containing index.html.
3. For tech.rebotics.in, configure the DNS CNAME for tech to your GitHub Pages hostname and set the repository Custom domain to tech.rebotics.in.
4. For www.reboticstechnologies.com, configure DNS as required by your domain registrar/GitHub Pages and set that custom domain in the GitHub Pages settings.
